# Agents: start here

This folder is an **Agent Skill**: the open SKILL.md format, which Claude, ChatGPT and
Codex all support. The complete operating manual is **`SKILL.md`**. Read it fully and
follow it.

If your tool installs skills, install this folder as one (keep the folder intact:
`SKILL.md` plus `scripts/`, `assets/` and `references/`). Otherwise just work from this
folder.

First command in any new environment: `python scripts/selftest.py`
